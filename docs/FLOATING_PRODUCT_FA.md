# دستبند شناور الوریا

نسخهٔ جدید بالای هوم، عکس واقعی محصول با زمینهٔ شفاف را نمایش می‌دهد. فقط یک عکس واضح لازم است. حرکت، تاب‌خوردن آرام و جابه‌جایی چند پیکسلی است؛ ساخت مدل سه‌بعدی و عکس‌های چندزاویه از این نسخه حذف شده‌اند.

## انتخاب محصول

در `/fa/admin/appearance` محصول و عکس آن را انتخاب کنید. حذف زمینه خودکار شروع می‌شود؛ تصویر اصلی دست‌نخورده می‌ماند. بند، سنگ‌ها و سوراخ وسط دستبند را در پیش‌نمایش بررسی کنید، اندازه را تنظیم کنید و «ذخیرهٔ دستبند شناور برای هوم» را بزنید. انتخاب هوم مستقل از هشت منتخب ذخیره می‌شود. خطای آماده‌سازی، تصویر ذخیره‌شدهٔ قبلی را جایگزین نمی‌کند.

پیش‌نمایش مدیریت و هوم از یک نمایش مشترک استفاده می‌کنند. حرکت در هوم قابل توقف است، بیرون صفحه یا در تب پنهان متوقف می‌شود و به تنظیم کاهش حرکت دستگاه احترام می‌گذارد. عکس با نسبت اصلی و بدون قاب یا زمینهٔ تصویری نمایش داده می‌شود. تا خروجی شفاف آماده نباشد، عکس مستطیلی در بخش شناور نمایش داده نمی‌شود.

## نصب ویندوز در C:\eloria

بستهٔ `eloria-floating-update.zip` را بیرون پوشهٔ پروژه استخراج کنید؛ سپس `install-floating-home.ps1` داخل بسته را با PowerShell اجرا کنید:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File 'C:\eloria-floating-update\install-floating-home.ps1' -ProjectRoot 'C:\eloria'
```

Git و Node.js نسخهٔ ۲۲ لازم است. نصب‌کننده بستهٔ مناسب نسخهٔ اولیه یا به‌روزرسانی قبلی را تشخیص می‌دهد و پیش از اعمال، فقط از فایل‌های کدِ تغییرکردنی نسخهٔ پشتیبان می‌گیرد. تعارض با تغییرات محلی را بازنویسی نمی‌کند و هیچ فایل env را نمی‌سازد یا تغییر نمی‌دهد. اگر مرحله‌ای شکست بخورد، همان‌جا متوقف می‌شود؛ متن خطای همان مرحله برای عیب‌یابی کافی است.

اگر کد و وابستگی‌ها نصب شده‌اند و توقف در مرحلهٔ سوم بوده است، پس از دریافت اصلاح نصب‌کننده، ادامه از همان مرحله ممکن است:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File 'C:\eloria\scripts\install-floating-home.ps1' -ProjectRoot 'C:\eloria' -Resume -LocalCutout
```

نصب‌کننده تنظیمات را با همان ترتیب Next.js می‌خواند؛ از جمله `.env.production.local` و `.env.local`. مقادیر مؤثر بدون چاپ‌شدن به Prisma و اجرای سایت منتقل می‌شوند. سرویس Python فقط تنظیمات اجرای خودش و توکن حذف زمینه را دریافت می‌کند؛ رمز دیتابیس یا درگاه به آن منتقل نمی‌شود. گزینهٔ `-Resume` اعمال دوبارهٔ بسته و نصب وابستگی‌های سایت را رد می‌کند.

گزینهٔ `-LocalCutout` فقط وقتی **هر دو** تنظیم حذف زمینه غایب باشند، آدرس loopback و یک توکن تصادفی را در حافظهٔ فرایند می‌سازد. هیچ فایل تنظیمات یا متغیر دائمی ویندوز تغییر نمی‌کند. تنظیمات موجود، ناقص یا نامعتبر خودکار جایگزین نمی‌شوند؛ فقط وضعیت `URL` و `TOKEN` گزارش می‌شود. این راه‌اندازی برای همین اجرای محلی است؛ پس از بستن فرایند، برای راه‌اندازی مجدد از همان دستور ادامه استفاده کنید. برای انتشار روی سرور، پیکربندی پایدار سرویس در محیط میزبان لازم است.

## ادامهٔ نصب بدون Docker

پس از خطای نبود Docker، بستهٔ `eloria-without-docker.zip` را بیرون پروژه استخراج و فایل `resume-floating-install.ps1` داخل آن را اجرا کنید. این بسته روی نسخهٔ شناور اولیه یا نسخهٔ اصلاح‌شدهٔ خواندن env اعمال می‌شود و از فایل‌های کد قبلی پشتیبان می‌گیرد:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File 'C:\eloria-without-docker\resume-floating-install.ps1' -ProjectRoot 'C:\eloria'
```

این نصب‌کننده Docker یا WSL را نصب یا اجرا نمی‌کند. ابتدا سرویس حذف زمینهٔ موجود را بررسی می‌کند. اگر آماده باشد همان سرویس استفاده می‌شود. برای سرویس محلیِ خاموش، Python نسخهٔ ۳٫۱۳ x64 موجود را پیدا می‌کند یا نصب‌کنندهٔ رسمی Python 3.13.16 را پس از کنترل SHA-256 و امضای ناشر دریافت و برای همین کاربر نصب می‌کند. PATH دائمی ویندوز تغییر نمی‌کند. کتابخانه‌ها در `.venv-cutout` پروژه و مدل در `.cache/eloria-cutout` نگهداری می‌شوند. اگر ONNX به کتابخانهٔ DLL مایکروسافت نیاز داشته باشد، بستهٔ رسمی Visual C++ نیز با بررسی امضای ناشر نصب می‌شود؛ در این حالت ویندوز ممکن است پنجرهٔ اجازهٔ نصب نشان دهد.

Python، کتابخانه‌ها و مدل در نصب اول به اینترنت نیاز دارند. نصب مجدد از فایل‌های سالمِ موجود استفاده می‌کند. پردازش عکس با CPU روی همین دستگاه انجام می‌شود و عکس محصول برای حذف زمینه به سرویس بیرونی ارسال نمی‌شود. این مدل حذف زمینه است؛ مدل سه‌بعدی ساخته نمی‌شود.

سرویس فقط روی `127.0.0.1:8765` گوش می‌دهد و توکن بین سایت و سرویس در حافظه به اشتراک گذاشته می‌شود. اجرای سایت تا آماده‌شدن سرویس منتظر می‌ماند. با خروج از اجرا، سرویس ساخته‌شدهٔ همان اجرا نیز متوقف می‌شود. اگر سرویس دیگری پورت را گرفته باشد، هیچ فرایند ناشناخته‌ای خودکار بسته نمی‌شود. محدودیت حافظهٔ کانتینر در اجرای مستقیم ویندوز وجود ندارد.

پس از نصب موفق، برای دفعات بعد فقط این دستور را اجرا کنید؛ build و migration و نصب وابستگی‌های سایت تکرار نمی‌شود:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File 'C:\eloria\scripts\start-eloria-native.ps1' -ProjectRoot 'C:\eloria'
```

هنگام استفاده از سایت پنجرهٔ اجرا باید باز بماند. برای توقف از Ctrl+C استفاده کنید. تنظیم سرویس به‌عنوان سرویس دائمی ویندوز یا انتشار روی هاست بخشی از این نصب محلی نیست.

نصب‌کننده migrationهای موجود پروژه را با `migrate deploy` اعمال می‌کند؛ reset، seed یا حذف جدول اجرا نمی‌کند. این نسخه migration جدیدی برای مدل سه‌بعدی ندارد. اگر بخشی از نصب سه‌بعدی قبلی تا دیتابیس پیش رفته باشد، جدول احتمالی آن خودکار حذف نمی‌شود؛ این نسخه از آن استفاده نمی‌کند.

پس از build، سایت محلی اجرا می‌شود. انتشار روی `eloriagallery.ir` مرحلهٔ جداگانه‌ای است. برای نصب روی سرور فعلی، همین کد و سرویس حذف زمینهٔ موجود کافی‌اند؛ آدرس‌ها و رازهای فعلی را حفظ کنید.

## بررسی انجام‌شده و محدودیت

تست‌های انتخاب عکس، محدودیت دریافت تصویر، حفظ رنگ و نسبت زیور، شفافیت مرکز دستبند و کنترل حرکت همراه کد هستند. کیفیت حذف زمینهٔ هر عکس باید در پیش‌نمایش بررسی شود، به‌خصوص برای بند نازک و سنگ شفاف. تصویر کم‌وضوح با حذف زمینه جزئیات تازه پیدا نمی‌کند.

TypeScript، بررسی خطاهای کد، تست‌های نمایش و حرکت و تست‌های نصب‌کننده با مخزن آزمایشی موفق بوده‌اند. کامپایل Next نیز موفق بوده، اما build کامل هنگام جمع‌آوری داده‌های صفحه به‌علت نبود `DATABASE_URL` در محیط آماده‌سازی متوقف شده است؛ env واقعی کاربر در این محیط در دسترس نبوده و تغییر نکرده است.

برای مسیر بدون Docker، حل وابستگی‌ها برای Python 3.13 و Windows x64، اجرای HTTP سرویس با عکس آزمایشی شفاف، احراز هویت، توقف با بسته‌شدن فرایند والد، حفظ env و چرخهٔ اجرای سایت/سرویس آزمایش شده‌اند. تست HTTP از مدل ساختگی و عکس از قبل شفاف استفاده می‌کند؛ کیفیت استنتاج مدل واقعی را اثبات نمی‌کند.

نصب واقعی Python و PowerShell روی دستگاه کاربر، دانلود و استنتاج مدل واقعی، اتصال به دیتابیس واقعی و نمایش روی دامنه از این محیط اجرا نشده‌اند. هیچ مدل سه‌بعدی ساخته نمی‌شود و هیچ ادعای انتشار زنده یا اندازه‌گیری سرعت مطرح نیست.
