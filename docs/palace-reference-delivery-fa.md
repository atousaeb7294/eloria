# تغییر بخش گنجینه‌های الوریا

این به‌روزرسانی روی نسخهٔ مخزن با شناسهٔ `56dbb14` آماده شده است. جای بخش زیر معرفی اصلی باقی می‌ماند. سایر بخش‌ها، تنظیمات سرور، دیتابیس، وابستگی‌ها و فایل‌های env تغییر نمی‌کنند.

- موبایل: سه کارت هم‌چینش با مرجع، صندوق روی پایهٔ کوتاه مرمری و فرش ایرانی؛ عکس‌ها و نوشته‌های اصلی مرجع حفظ شده‌اند.
- دسکتاپ: تصویر اصلی کاخ و هشت منتخب، همراه دو آتشدان در دو طرف.
- ورود: درِ صندوق باز می‌شود، دوربین در ۳۸۰ میلی‌ثانیه کمی نزدیک می‌شود و مسیریابی اصلی از همان لحظهٔ کلیک شروع می‌شود. پنجره یا صفحهٔ واسط اضافه نشده است.
- تصاویر داخل صندوق متناسب با طلا، نقره و بافت هستند. تصاویر به WebP با نام دارای هش تبدیل شده‌اند؛ تصاویر هر دستگاه جداگانه و به‌صورت lazy بارگیری می‌شوند.
- تصاویر منتخب از مرجع هستند. اگر نام دقیق در کاتالوگ پیدا شود، لینک به محصول واقعی می‌رود؛ در غیر این صورت، جست‌وجوی همان نام در فروشگاه باز می‌شود.

## اعمال بسته

ابتدا از تغییرات محلی خود بکاپ بگیرید. فایل‌های پوشهٔ `files/` در ZIP را با همان ساختار روی ریشهٔ پروژه جایگزین/اضافه کنید. این پوشه فایل env ندارد.

راه دیگر، در صورت استفاده از Git، اعمال فایل patch از ریشهٔ پروژه است:

```sh
git apply --check /path/to/eloria-treasuries.patch
git apply /path/to/eloria-treasuries.patch
```

از یکی از دو روش استفاده کنید. ساخت عادی پروژه با همان env فعلی روی میزبان شما انجام می‌شود:

```sh
npm run typecheck
node --import tsx scripts/test-palace-recovery.ts
npm run build
```

TypeScript و تست‌های مؤلفه، مسیرها، حرکت، قطع API و دارایی‌های تصویری در محیط آماده‌سازی موفق بودند. ساخت کامل به محدودیت ابزارهای سیستم این محیط برخورد کرده است: ابتدا خطای native SWC و در تلاش با WASM خطای `uv_resident_set_memory`. بنابراین موفقیت build نهایی یا ارزیابی تصویری در مرورگر ادعا نمی‌شود. پیش از انتشار، build و نمای موبایل و دسکتاپ را روی میزبان اصلی بررسی کنید.

این بسته هنوز روی GitHub یا `eloriagallery.ir` منتشر نشده است.
