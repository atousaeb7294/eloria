# نقشه اجرایی ارشد الوریا — رایگان و قابل نگهداری

این سند نقشه عملیاتی فروشگاه است؛ امکاناتی که اکنون فعال‌اند از برنامه‌های نیازمند داده واقعی جدا شده‌اند تا هیچ قابلیت نمایشی یا ادعای غیرواقعی وارد Production نشود.

## ۱. تجربه، فشن و تبدیل

- فعال: Home ادیتوریال با چیدمان نامتقارن، سه اثر منتخب روزانه و CTA روشن.
- فعال: موشن فقط با `transform` و `opacity`، پشتیبانی از Reduced Motion و تعامل لمسی سریع.
- فعال: انتخاب هوشمند روزانه بر پایه تازگی، موجودی، فروش، بازدید و محبوبیت.
- فعال: راهنمای انتخاب هوشمند، محصولات مرتبط، علاقه‌مندی، پیگیری قیمت و موجودی.
- اقدام مدیریتی: ماهانه نرخ کلیک Home، افزودن به سبد و تکمیل خرید در پنل Intelligence بررسی شود.

## ۲. عملکرد و Core Web Vitals

- فعال: تصویر Hero با فرمت بهینه Next Image، اندازه واکنش‌گرا و کیفیت کنترل‌شده.
- فعال: Lazy Loading تصاویر پایین صفحه، `content-visibility` و cache رسانه.
- فعال: Dynamic Import و بارگذاری افکت‌های تزئینی در زمان بیکاری مرورگر.
- فعال: Prefetch هوشمند مسیر محصول و واکنش سریع روی لمس/کلیک.
- هدف: LCP زیر ۲.۵ ثانیه، INP زیر ۲۰۰ میلی‌ثانیه و CLS زیر ۰.۱ روی موبایل واقعی.

## ۳. SEO هوشمند و محتوا

- فعال: canonical، sitemap، Product/Organization schema، metadata و ALT.
- فعال: سلامت روزانه محتوا و شناسایی شرح/ALT/مقاله قدیمی یا ناقص.
- فعال: پیش‌نویس هوشمند مقاله با قالب رایگان یا مدل محلی Ollama؛ انتشار فقط با تأیید مدیر.
- فعال: راهنماهای سایز انگشتر و مچ، اجرت، طلای سفید/زرد، هدیه و نگهداری.
- اقدام مدیریتی: هفته‌ای یک پیش‌نویس بازبینی و پس از بررسی صحت منتشر شود.

## ۴. هوش فروش و عملیات

- فعال: RFM مشتری، Funnel، Attribution/UTM، شتاب هفتگی محصول و Daily Briefing.
- فعال: Timeline هر قطعه از ثبت، وزن و تغییر قیمت تا رزرو، فروش و مرجع پرداخت.
- فعال: تخفیف ثابت ۵۰٬۰۰۰ تومانی `ELORIA50` فقط برای اولین خرید و با کنترل سرور.
- فعال: محاسبه مجدد قیمت، موجودی و تخفیف در Server؛ Front-end مرجع مالی نیست.

## ۵. امنیت و اعتماد

- فعال: 2FA مدیر، rate limit، secure cookie، محدودیت ورود، ثبت فعالیت و سطح دسترسی.
- فعال: Turnstile، کنترل Origin/CSRF، توکن امضاشده و جلوگیری از دستکاری مبلغ.
- فعال: سیاست‌های حقوق مشتری، ارسال رایگان و راه ارتباط مستقیم `09180079556`.
- اقدام زیرساخت: Backup خودکار رمزگذاری‌شده PostgreSQL روزانه و آزمون Restore فصلی.

## ۶. PWA و دسترس‌پذیری

- فعال: Manifest و Service Worker برای نصب روی موبایل.
- فعال: مسیرهای حساس API/Admin/Checkout وارد cache عمومی نمی‌شوند.
- فعال: جهت RTL/LTR، فوکوس صفحه‌کلید، ALT و احترام به Reduced Motion.

## ۷. ابزارهای رایگان

- Next.js، React، Prisma، PostgreSQL، Motion و GSAP: متن‌باز.
- هوش پیش‌فرض Template: رایگان و بدون API پولی.
- هوش محلی اختیاری: Ollama + Qwen؛ هزینه API ندارد و به منابع سیستم نیاز دارد.
- پایش: Lighthouse و ابزارهای مرورگر؛ رایگان.
