## بررسی‌های انجام‌شده

- `npm run typecheck`: موفق.
- `npm run lint`: موفق.
- `npm run test:audit-regressions`: مجموعهٔ حرکت، رسانه، وزن/جنس/قیمت، OTP/پرداخت و SEO موفق؛ دو تست داستان و رسانهٔ ارسالی نیز جداگانه موفق شدند و به همین فرمان اضافه شده‌اند.
- `npm run audit:quality`: موفق؛ بررسی قراردادهای ایستا و حرکت، نه تأیید اجرای تست‌های مرورگر.
- `npm run audit:security`: همهٔ کنترل‌های قابل بررسی موفق؛ کنترل Docker healthcheck به علت نبود Dockerfile در فایل ارسالی ناموفق/قابل‌تأیید نیست. Dockerfile کاربر تغییر داده نشده است.
- آزمون رسانه از sharp واقعی استفاده می‌کند؛ storage/پرداخت/دیتابیس در تست‌های جدید شبیه‌سازی شده‌اند، اتصال به دیتابیس پارس‌پک انجام نشده است.
- schema دیتابیس با نسخهٔ پیشین یکسان است؛ migration جدیدی اضافه نشده است.
- ساخت production قبلاً در این محیط با خطای SWC و `uv_resident_set_memory` متوقف شد. موفقیت build نسخهٔ تطبیق‌یافته ادعا نمی‌شود؛ نصاب آن را روی ویندوز شما اجرا می‌کند و در صورت خطا می‌ایستد.
- منطق بسته‌بندی، checksum فایل‌ها، اعمال روی کپی snapshot و خارج‌بودن ENV از payload بررسی شده‌اند. خود PowerShell در این محیط در دسترس نیست؛ اجرای ویندوزی نصاب هنوز تأیید نشده است.
