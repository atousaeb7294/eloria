## مدیریت عکس و انتخاب محصول

از پنل `https://eloriagallery.ir/fa/admin/products` وارد ویرایش محصول شوید:

1. **عکس:** در تصاویر محصول، عکس دلخواه را بارگذاری و اصلی کنید. همان عکس در کارت خانه و صفحهٔ محصول استفاده می‌شود. برای لینک خارجی، از دامنه‌های مجاز فعلی سایت استفاده کنید.
2. **منتخب‌های الوریا:** گزینهٔ «نمایش در منتخب‌های الوریا (صفحهٔ خانه)» را برای آثار دلخواه روشن کنید. عدد «ترتیب نمایش» کمتر، جایگاه جلوتر دارد. برای دقیق‌ترین چیدمان از اعداد متفاوت استفاده کنید. سقف این بخش ۹ اثر است. اگر همهٔ علامت‌ها را بردارید، حالت خودکار فعال می‌شود.
3. **سه عکس زیر هر صندوقچه:** سه محصول همان گنجینه که عکس اصلی دارند و کمترین «ترتیب نمایش» را دارند، نشان داده می‌شوند. مثلاً به سه انتخاب خود عددهای ‎-۳۰، ‎-۲۰، ‎-۱۰ بدهید و بقیه را روی ۰ یا بیشتر نگه دارید. این فیلد در ترتیب معمول محصولات هم اثر دارد. محصول دارای هر دو فلز می‌تواند زیر هر دو صندوقچه باشد.
4. فقط محصولات منتشرشده یا ناموجود، در مجموعهٔ فعال و دارای عکس نمایش داده می‌شوند. پیش‌نویس و بایگانی نمایش داده نمی‌شوند.

به‌روزرسانی صفحهٔ باز هر دقیقه انجام می‌شود و کش API کوتاه است؛ پس از ذخیره، صفحه را تازه‌سازی کنید. در نبود تصویر، نشان برند نمایش داده می‌شود؛ عکس یک محصول دیگر جای آن قرار نمی‌گیرد. در قطعی موقت، دکمهٔ تلاش دوباره و مسیر ورود به فروشگاه باقی می‌مانند.

هنگام بررسی عمومی سایت، API هشت محصول با عکس واقعی و بدون علامت منتخب برگرداند. برای تعیین انتخاب شخصی، از گزینهٔ بالا استفاده کنید؛ داده‌های فروشگاه زنده تغییر داده نشده‌اند.

## نصب در C:\eloria و ارسال به GitHub

پیش‌نیازها: Git، Node.js نسخهٔ ۲۲، دسترسی خودتان به مخزن و تنظیم نام و ایمیل Git. برنامهٔ در حال اجرای محلی را پیش از build متوقف کنید. فایل‌های `.env` موجود را نگه دارید. اگر مخزن را برای اولین بار clone می‌کنید، تنظیمات واقعی محیط پروژه را طبق `.env.example` در دستگاه خود وارد کنید؛ اطلاعات محرمانه را به GitHub نفرستید.

فایل ZIP را در Downloads ذخیره کنید. در PowerShell:

```powershell
Expand-Archive -LiteralPath "$HOME\Downloads\eloria-royal-update.zip" -DestinationPath 'C:\eloria-royal-update'
powershell -ExecutionPolicy Bypass -File 'C:\eloria-royal-update\Install-EloriaUpdate.ps1' -ProjectPath 'C:\eloria' -Publish
```

اسکریپت در صورت نبود پوشه، مخزن را clone می‌کند. روی مخزن دارای تغییر ذخیره‌نشده متوقف می‌شود. ابتدا صحت پچ و بایت فایل‌ها را می‌سنجد، شاخهٔ تازه می‌سازد، تغییرات را اعمال می‌کند، وابستگی‌ها را با `npm ci` نصب می‌کند، کلاینت Prisma را تولید می‌کند و typecheck، آزمون‌های مرتبط و build را اجرا می‌کند. فقط پس از موفقیت بررسی‌ها commit ساخته می‌شود. با `-Publish` همان شاخه به GitHub فرستاده می‌شود و لینک ساخت Pull Request چاپ می‌شود. ورود GitHub را خود Git روی دستگاه شما مدیریت می‌کند؛ کلید یا رمز را داخل اسکریپت نگذارید.

برای آماده‌سازی فقط روی دستگاه، `-Publish` را حذف کنید. ارسال بعدی:

```powershell
Set-Location 'C:\eloria'
git push --set-upstream origin HEAD
```

پس از ارسال، Pull Request به `main` را بسازید، بررسی‌های فعلی GitHub را منتظر بمانید، صفحه را بررسی کنید و سپس merge کنید. انتشار دامنه از همان گردش کار فعلی میزبانی شما انجام می‌شود؛ اسکریپت به تنظیمات میزبانی دست نمی‌زند.

اگر `git apply --check` خطا داد، پچ با نسخهٔ فعلی شما سازگار نیست یا قبلاً اعمال شده است؛ آن را به زور اعمال نکنید. اگر typecheck یا build متوقف شد، هیچ push خودکاری انجام نمی‌شود؛ تغییرات روی همان شاخه می‌مانند. پس از رفع علت:

```powershell
Set-Location 'C:\eloria'
npm run typecheck
node --import tsx scripts/test-palace-recovery.ts
npm run build
# فقط پس از موفقیت دستورهای بالا:
git diff --cached --check
git commit -m 'Update royal treasury artwork and curated product previews'
git push --set-upstream origin HEAD
```

برای دیدن نسخهٔ محلی بعد از نصب:

```powershell
Set-Location 'C:\eloria'
npm run dev
```

نشانی چاپ‌شده در خروجی را باز کنید و مسیر `/fa#treasury-gold` را ببینید. اتصال تصاویر واقعی در نسخهٔ محلی به تنظیمات دیتابیس و فضای تصاویر خود پروژه نیاز دارد؛ تصویر ساختگی به‌عنوان محصول اضافه نشده است.

## بررسی‌های انجام‌شده و محدودیت‌ها

- TypeScript روی Node.js 22.23.3 موفق بود.
- آزمون‌های رفتار رابط با محیط شبیه‌سازی‌شده موفق بودند: هویت عکس/لینک محصول، انتخاب و ترتیب، سه مقصد، انتظار برای بازشدن، کلیک سریع، انتخاب محصول حین انیمیشن، برگشت، Escape، کاهش حرکت، وضعیت خالی/قطعی، تلاش مجدد و Save-Data.
- آزمون منبع و بررسی فاصله‌های پچ موفق بودند. اصل تصاویر با SHA-256 تطبیق داده شد. هدر، هیرو، مقدمه و استایل عمومی با نسخهٔ پایه تطبیق داده شدند.
- ساخت production در این محیط کامل نشد: باینری SWC با خطای محیطی stacker متوقف شد؛ مسیر جایگزین WASM نیز به خطای `uv_resident_set_memory` در محیط محدود برخورد کرد. هیچ وابستگی یا تنظیم production برای پنهان‌کردن این خطا تغییر نکرده است. اسکریپت نصب build واقعی را روی دستگاه شما الزامی می‌کند.
- بررسی بصری مرورگر و اجرای PowerShell روی ویندوز در این محیط انجام نشده‌اند. پیش از merge، عرض‌های ۳۲۰، ۳۹۰، ۷۶۸ و ۱۴۴۰ پیکسل، کلیک روی هر سه صندوقچه و هر کارت محصول، و برگشت مرورگر را بررسی کنید.
- اتصال مدیریتی به دیتابیس و انتشار روی سایت زنده انجام نشده است. API عمومی سایت فقط برای خواندن وضعیت محصولات بررسی شد.
