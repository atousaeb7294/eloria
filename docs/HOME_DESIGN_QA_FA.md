# گزارش بررسی هوم الوریا

تاریخ بررسی/بسته‌بندی: ۲۱–۲۲ اکتبر ۲۰۲۶. مبنا: `17e08171f58443a74f3f4bf29f7f19b1f8b3fc61`.

بسته شامل کد اصلاح و ابزار نصب/آزمون است؛ تأیید اجرای production یا بازبینی دیداری گوشی و دسکتاپ محسوب نمی‌شود.

| بررسی | وضعیت و حد نتیجه |
| --- | --- |
| TypeScript | `npm run typecheck` موفق. |
| ESLint | فایل‌های TypeScript/JavaScript تغییرکرده و جدید بدون خطا. |
| Prisma | generate و validate موفق؛ به دیتابیس واقعی متصل نشدیم. |
| انتخاب محصولات و دریافت عکس | آزمون ۸ شناسهٔ متفاوت و معتبر، سقف دریافت ۸ MB، دریافت خالی و لغو جریان بزرگ موفق. |
| چهار آزمون مصنوعی تصویر | حفظ اصل، رنگ، نسبت و سوراخ شفاف؛ بزرگ‌سازی متناسب تصویر کوچک؛ رد ماسک نامعتبر؛ حفظ آلفای موجود و ترتیب opt-out تأیید شدند. هیچ inference واقعی در این آزمون‌ها اجرا نمی‌شود. |
| هندسهٔ قاب | حاشیهٔ امن بزرگ‌ترین ابعاد خروجی برای جاگیری در دایره محاسبه و آزمایش شد. این بررسی جای آزمون مرورگر را نمی‌گیرد. |
| patch | بررسی `git diff --check` و اعمال روی checkout تمیز commit مبنا انجام شد؛ فایل‌ها با نسخهٔ اصلاح‌شده مقایسه شدند. |
| build نهایی Next | تأیید نشده: در تلاش قبلی کامپایلر native با `stacker` / `GenericFailure` هنگام بارگذاری `next.config.ts` متوقف شد. محیط Node 24.19 است و پروژه Node 22 می‌خواهد؛ علت دقیق خطای native تعیین نشد. |
| موبایل و دسکتاپ | سرویس preview محیط راه‌اندازی نشد و mailbox آن در دسترس نبود. Playwright و بازبینی screenshot اجرا نشده‌اند. مجموعهٔ آزمون برای اجرا روی مقصد موجود است. |
| migration و ذخیرهٔ واقعی مدیریت | تنظیمات/دیتابیس واقعی در دسترس نبود؛ اجرای migration و جریان کامل ذخیره تأیید نشده‌اند. |
| پردازش هر هشت عکس واقعی | یک نمونهٔ اولیه بررسی شد؛ آزمون دسته‌ای کامل نشد. یک تلاش با کمبود حافظه متوقف شد و پردازش به فرایند جدا برای هر عکس تغییر کرد. تلاش بعدی به‌دلیل اتصال telemetry توسط بررسی خودکار ایمنی رد شد. |
| اتصال جانبی پردازشگر | ابزار آزمون اتصال Microsoft telemetry را حتی پس از opt-out گزارش کرد؛ محتوای ارسال‌شده مشخص نبود. پردازش واقعی روی میزبان تکرار نشد. نصب نهایی به Docker با شبکهٔ `internal` تغییر کرد. |
| Docker و PowerShell | در این محیط موجود نبودند؛ build و جداسازی شبکهٔ کانتینر و اجرای واقعی PowerShell تأیید نشده‌اند. اسکریپت‌ها بازبینی شده‌اند. |

پیش از انتشار، دستور نصب را با Node 22 و Docker روی سیستم مقصد اجرا کنید، یک محصول هوم و هشت منتخب را در مدیریت ذخیره کنید، سپس `npm run test:home-browser` را اجرا و تصاویر گزارش را بازبینی کنید. تست‌ها عرض 1440، Pixel، عرض 320 و تبلت را پوشش می‌دهند. این مجموعه به انتخاب محصولات واقعی نیاز دارد و از E2E عمومی جداست.

کیفیت جداسازی بند ظریف و زمینهٔ هم‌رنگ باید با اصل عکس مقایسه شود. الگوریتم اصل فایل را تغییر نمی‌دهد، اما تضمین نمی‌کند هر ماسک واقعی بی‌خطا باشد. `contain` و فاصلهٔ امن، کشیدگی و سرریز را کنترل می‌کنند. نمایش شناور حرکت همان عکس است، نه مدل هندسی واقعی ۳۶۰ درجه.

مرجع ظاهر سورس ذخیره‌شدهٔ نسخهٔ سوم طرح آفلاین بود؛ فایل پیوست قبلی در مسیر اعلام‌شده موجود نبود و تطبیق بایت‌به‌بایت ممکن نشد. تصویر ساختگی به‌عنوان screenshot آزمون ارائه نشده است. کد به سایت اصلی یا GitHub ارسال نشده است.

## به‌روزرسانی درجا در C:\eloria

نصاب جدید فقط patch کد را اعمال می‌کند؛ فایل‌های `.env*` از بستهٔ تغییرات حذف شده‌اند و بررسی تنظیمات پردازش نیز اکنون فقط خواندنی است. نصب وابستگی، اجرای سرویس، Prisma generate یا migration توسط نصاب درجا اجرا نمی‌شود. فعال‌سازی قابلیت‌های دارای جدول/سرویس جدید مرحله‌ای جداگانه است.

آزمون یکپارچهٔ Node/Git با مخزن و remote محلیِ آزمایشی موفق بود: ارسال یک commit فقط با مسیرهای مجاز، پشتیبان فایل‌های قبلی، حفظ `.env` و `.env.production.local`، دادهٔ SQLite، فایل آپلود و تغییر محلی نامرتبط؛ توقف در تغییر ذخیره‌نشدهٔ فایل هدف، فایل stage‌شده، برخورد با فایل untracked، خرابی هش patch، commit محلی منتشرنشده، مسیر حساس یا لینک؛ جلوگیری از push در صورت افزودن فایل غیرمجاز توسط hook. آزمون از فایل‌ها و داده‌های مصنوعی استفاده می‌کند و هیچ اتصال GitHub واقعی برای ارسال نداشت.

اجرای PowerShell روی ویندوز یا دسترسی به مسیر واقعی `C:\eloria` در این محیط انجام نشده است. محدودیت‌های قبلیِ آزمون دیداری و build همچنان برقرارند.
