# بسته نهایی اصلاحات ظاهری ELORIA — نسخه 6.0

این نسخه بر پایه Phase 5.6 ساخته شده و تمام اصلاحات ظاهری باقی‌مانده را در یک بسته جمع می‌کند.

## اصلاحات سراسری

- یکدست‌سازی پنل‌ها، دکمه‌های اصلی و فرعی، فیلدهای فرم و رنگ‌های طلایی/سبز
- اضافه‌شدن Scroll Reveal کنترل‌شده برای بخش‌ها و کارت‌ها
- اضافه‌شدن نوار پیشرفت اسکرول در بالای صفحه
- حفظ کامل Reduced Motion و غیرفعال‌شدن حرکت‌های غیرضروری برای کاربران حساس به انیمیشن
- بهینه‌سازی موتور کارت‌های سه‌بعدی با requestAnimationFrame
- جلوگیری از اجرای افکت Tilt روی موبایل و دستگاه‌های Pointer Coarse
- اضافه‌شدن Scrollbar هماهنگ با هویت بصری ELORIA
- بهبود حالت Focus و استفاده با کیبورد

## صفحات و مسیرهای جدید

- `/{locale}/contact`
- `/{locale}/order-tracking`
- `/{locale}/order/success`
- `/{locale}/order/failed`
- `/{locale}/policies/privacy`
- `/{locale}/policies/terms`
- `/{locale}/policies/shipping`
- `/{locale}/policies/returns`

صفحه تماس و پیگیری از نظر UI آماده‌اند، اما تا زمان اتصال Backend اطلاعات واقعی ارسال یا دریافت نمی‌کنند. این موضوع داخل خود صفحات نیز شفاف نوشته شده است.

## بهبود صفحات فعلی

- انیمیشن ورود برای بخش‌های صفحه اصلی، درباره ما، دسته‌بندی‌ها و محصولات
- حالت Empty State یکدست برای کاتالوگ و دسته‌بندی‌های بدون محصول
- لینک تماس هدر و منوها به صفحه تماس واقعی منتقل شد
- فوتر کامل با مسیرهای فروشگاه، پشتیبانی، پیگیری سفارش و قوانین
- اضافه‌شدن لینک‌های قوانین به منوی موبایل
- بهبود ساختار ریسپانسیو صفحات جدید و موجود

## تست ظاهری خودکار

تست Playwright واقعی جایگزین تست نمونه قبلی شد. تست جدید موارد زیر را بررسی می‌کند:

- عرض 320 پیکسل
- عرض 375 پیکسل
- عرض 430 پیکسل
- تبلت 768 پیکسل
- دسکتاپ 1440 پیکسل
- نبود Horizontal Overflow
- بازشدن منوی موبایل
- نمایش لینک تماس و پیگیری سفارش
- صفحات فارسی و انگلیسی

اجرای تست:

```powershell
npm run test:visual
```

## دستورات کنترل نهایی

```powershell
npm run lint
npm run build
npm run dev
```

## نکات مهم

- فایل `.env` داخل بسته قرار ندارد. فایل `.env` فعلی پروژه خود را نگه دارید.
- منطق دیتابیس، قیمت‌گذاری، موجودی و Checkout تغییر نکرده است.
- قوانین موجود در صفحات جدید، متن اولیه ساختاری هستند و پیش از فروش عمومی باید بررسی حقوقی شوند.
- فرم تماس و پیگیری سفارش هنوز به API عملیاتی متصل نیستند.
